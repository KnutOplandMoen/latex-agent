# latex-lang package

Custom CodeMirror 6 LaTeX extensions. See also `apps/web/components/editor/CLAUDE.md` for the full CodeMirror 6 patterns and rules.

This package provides:
- LaTeX syntax highlighting (via `codemirror-lang-latex`)
- Custom snippets (`latexSnippets()`)
- Custom linting (`latexLinter()`)
- Any other LaTeX-specific editor extensions

All extensions must follow the CodeMirror 6 patterns described in `apps/web/components/editor/CLAUDE.md`.
